Installing Hermes Agent

From zero to your first AI conversation in ~10 minutes. Based on Hermes Agent for Dummies by Ken Thornton.

What You'll Need

  • Linux, macOS, or Windows (WSL2)
  • curl and bash (standard on most systems)
  • An API key from an AI provider (OpenRouter recommended for beginners)

Step 1: Install Hermes

1

Run the installer

curl -fsSL https://get.hermes.sh | bash

The installer handles everything:

  • Installs uv (fast Python package manager in Rust)
  • Creates an isolated Python 3.11 virtual environment
  • Installs hermes-agent with all extras
  • Creates symlink at ~/.local/bin/hermes
  • Sets up ~/.hermes/ directory for config, memories, skills
⚡ Pro tip

Want to see what the installer does before running? View the script first: curl -fsSL https://get.hermes.sh | less

Step 2: Reload Your Shell

2

Make hermes available

# bash
source ~/.bashrc

# zsh (macOS default)
source ~/.zshrc

# fish
source ~/.config/fish/config.fish

Verify it works:

hermes --version
⚠ Common issue

command not found: hermes → You forgot to reload your shell. Run the appropriate source command above.

Step 3: Run the Setup Wizard

3

Configure your AI provider and model

hermes setup

The wizard walks you through 4 decisions:

  1. Provider — Choose OpenRouter (recommended) for 200+ models via one key. Also supports OpenAI, Anthropic, NVIDIA NIM, Nous Portal, etc.
  2. API Key — Paste your key. Stored securely in ~/.hermes/.env (separate from main config).
  3. Model — Pick a model. Good defaults: anthropic/claude-3.5-sonnet, openai/gpt-4o, meta-llama/llama-3.1-70b-instruct. Change anytime later.
  4. Tools — Enable file reading, web browsing, code execution. Defaults are sensible.
🔑 Get an OpenRouter key

1. Go to openrouter.ai → Sign up
2. Settings → Keys → Create Key
3. Copy the key (starts with sk-or-v1-)

Step 4: Start Your First Conversation

4

Talk to your agent

hermes chat

You'll see a prompt. Type naturally:

>> Hello! What can you help me with?
>>> Write a Python script that backs up my dotfiles to GitHub
>>> Explain the difference between async and threading in Python

Press Ctrl+C to interrupt, Ctrl+D or /exit to quit.

Step 5: Optional — Connect to Telegram

5

Chat from your phone

Create a bot via @BotFather on Telegram, then:

hermes gateway setup

Paste the bot token and your Telegram user ID. Now you have Hermes in your pocket.

Where Things Live

~/.hermes/
├── config.yaml      # Non-secret configuration
├── .env             # API keys, secrets (gitignored)
├── SOUL.md          # Agent identity/personality
├── memories/
│   ├── MEMORY.md    # Agent's persistent facts
│   └── USER.md      # Your profile
├── skills/          # All skills (built-in + custom)
├── sessions/        # Per-platform chat history
├── state.db         # SQLite with full-text search
├── cron/
│   ├── jobs.json    # Scheduled jobs
│   └── output/      # Cron run logs
├── plugins/         # Custom plugins
├── hooks/           # Lifecycle hooks
├── skins/           # CLI themes
└── logs/            # agent.log, gateway.log, errors.log
🧹 Clean uninstall

Hermes is completely self-contained. To remove: rm -rf ~/.hermes ~/.local/bin/hermes — no system pollution.

Next Steps

  • Customize personality: Edit ~/.hermes/SOUL.md
  • Add skills: hermes skills install from the Skills Hub
  • Create profiles: hermes profile create work for separate contexts
  • Schedule tasks: hermes cron add "daily summary" "0 8 * * *"
